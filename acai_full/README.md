# AÇAI – App Completo

## Como usar neste repositório

1. Apague **tudo** que existe atualmente no seu repositório GitHub.
2. Faça upload de **todo o conteúdo** desta pasta (ou faça push deste projeto).
3. Vá na aba **Actions** → rode o workflow **Build AÇAI APK**.
4. Baixe o artefato `acai-release-apk`.

## Estrutura
- `lib/` → código Dart (fachada, PIN, chamadas)
- `android/` → projeto Android completo
- `assets/` → banner e ícone
- `.github/workflows/main.yml` → gera o APK automaticamente
